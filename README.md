# Portfolio Nhiếp Ảnh Cưới

Trang giới thiệu (landing page) **tĩnh** — portfolio nhiếp ảnh cưới một trang: hero ấn tượng và bộ sưu tập 3 phong cách ngoại cảnh, studio, truyền thống.. Trang được dựng bằng HTML, CSS và JavaScript thuần, không cần bước biên dịch.

> Mọi tên, số điện thoại, địa chỉ và số liệu trên trang đều là **dữ liệu mẫu**. Giá hiển thị là **giá mẫu**. Biểu mẫu (nếu có) chỉ là giao diện minh họa: không gửi dữ liệu đi đâu và không có backend.
